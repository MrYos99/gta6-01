# NEONFALL 2100

A complete open-world crime game in the spirit of GTA 6, built for the [make.fun bounty gta6-01](https://make.fun/bounty/gta6-01).

**Voltspire, year 2107** — a sun-soaked neon city. Dual-mode hover-cars (street + flight), car stealing as the upgrade path, robot police with 5-star escalation, 4 EM weapons with battery systems, and 6 missions to clear a 50,000-credit debt.

Built with three.js. Playable offline in a desktop browser from static files.
